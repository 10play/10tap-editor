# Migrating to v1.0

This guide will help you migrate from pre-1.0 versions to v1.0 of 10tap-editor.

## Breaking Changes

### Custom Keyboard Removed

:::tip
Custom keyboards are back in 1.1, with the same API. See the [1.1 migration guide](./v1.1.md).
:::

The custom keyboard functionality has been removed in v1.0. This includes:

- `CustomKeyboard` component
- `CustomKeyboardUtils` API
- `ColorKeyboard` and `CustomKeyboardExtension`
- the `TenTapView` native component
- the `colorKeyboard` key of `EditorTheme`, and the `Color` and `ColorKeyboardTheme` types
- the `codegenConfig` entry (`RNTenTapViewSpec`) in the package's `package.json`
- Color keyboard example
- Custom keyboard example

### HistoryBridge Renamed

TipTap v3 renamed its History extension to UndoRedo, so `HistoryBridge` is now named `undoRedo` instead of `history`. Code that looks bridges up by name, such as `TenTapStartKit.filter((b) => b.name !== 'history')`, must use `'undoRedo'`. Custom editor bundles built with 0.7.x didn't receive the HistoryBridge config from a 1.0 app; 1.1 sends it under both names.

### KeyboardAvoidingView Behavior Changed

The `behavior` prop for `KeyboardAvoidingView` has been simplified in v1.0.

**Before (Pre-1.0):**
```tsx
<KeyboardAvoidingView
  behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
  style={exampleStyles.keyboardAvoidingView}
>
  <Toolbar editor={editor} />
</KeyboardAvoidingView>
```

**After (v1.0):**
```tsx
<KeyboardAvoidingView
  behavior={'padding'}
  style={exampleStyles.keyboardAvoidingView}
>
  <Toolbar editor={editor} />
</KeyboardAvoidingView>
```

The platform-specific check is no longer needed - use `'padding'` for both iOS and Android.

### SafeAreaView Import Changed

`SafeAreaView` now uses `react-native-safe-area-context` instead of `react-native`.

**Before (Pre-1.0):**
```tsx
import { SafeAreaView } from 'react-native';
```

**After (v1.0):**
```tsx
import { SafeAreaView } from 'react-native-safe-area-context';
```

Make sure you have `react-native-safe-area-context` installed and configured properly.

## Updated Dependencies

v1.0 is based on Tiptap v3, which brings improved performance and new features.

Update your dependencies:
```bash
yarn add @10play/tentap-editor@latest react-native-webview@latest
```

For iOS, update pods:
```bash
cd ios && pod install
```
