# TenTap Expo example

An Expo (SDK 57, new architecture) app that runs `@10play/tentap-editor` from
the workspace source in `../src`. It uses a development build, so the
library's native keyboard module is linked; the `ios/` and `android/` folders
are generated by `expo prebuild` and not committed.

From the repo root:

```sh
yarn install
yarn example:expo ios        # expo run:ios (prebuilds, builds and launches)
yarn example:expo android    # expo run:android
yarn example:expo web        # expo start --web
yarn example:expo start      # Metro for an installed dev build
yarn example:expo typecheck
```

Maestro flows live in `.maestro` (`maestro test example-expo/.maestro`); they
open the installed development build on `METRO_URL` (default
`http://localhost:8081`). The long-typing flows in `.maestro/caret` check that
the typed line stays above the toolbar; run them one at a time.

Screens: a basic editor with the toolbar, dynamic height, a custom keyboard
(ColorKeyboard) in the inline and the overlay layout, and two editors on one
screen. The screens share a small theme (`src/theme.ts`) and follow the
system light or dark appearance; in dark mode the editors use
`darkEditorTheme` and `darkEditorCss`.

`metro.config.js` maps `@10play/tentap-editor` to `../src`, resolves React and
the native packages from this app's `node_modules`, and on web swaps
`react-native-webview` for `@10play/react-native-web-webview`.
`react-native.config.js` autolinks the library's native code from the repo root.
